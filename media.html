Pick an exercise, drag your photos or a video onto it and check how it looks. When you're happy, press Put on the website.

Never use photos or videos of patients. Only show yourself or a colleague who has agreed to be on a public website. Hidden details such as where a photo was taken are removed before anything is uploaded.

You only do this once on each computer. It lets this page put files on your website for you. Without it, this page can't change anything.

  1. Open GitHub's "new key" page (sign in as PhysioRepSheet if it asks).
  2. Token name: type RepSheet photos. Expiration: pick 1 year (or the longest it offers).
  3. Repository access: choose Only select repositories, then pick Physiotherapy-Exercises.
  4. Permissions: open Repository permissions, find Contents and set it to Read and write. Leave everything else alone.
  5. Press Generate token at the bottom, copy the long code it shows (it starts github_pat_) and paste it below.

This page can put files on your website. The key is only kept in this browser on this computer.
